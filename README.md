### EduApp Backend

**C# / .NET / ASP.NET Core / FastEndpoints / REST API / NUnit**

Rozwijany backend aplikacji edukacyjnej zbudowany w architekturze warstwowej, z podziałem na warstwy API, Application, Domain oraz Infrastructure.

Projekt obejmuje obsługę użytkowników i pytań edukacyjnych, REST API, mapowanie modeli DTO/DAO, dependency injection, wzorzec repository/service oraz testy jednostkowe logiki domenowej.

Projekt jest aktywnie rozwijany; planowany jest moduł generowania pytań oraz integracja z modelem AI tworzonym w Pythonie.
